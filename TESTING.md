# Проверка игры «Богатей»

## Автоматические тесты

Запуск: `python manage.py test`. Прошли **27 из 27** на SQLite и отдельно на PostgreSQL 17.11.

| Модуль | Что проверено |
|---|---|
| Модели | Создание и чтение всех шести моделей; связи с пользователем, сохранениями, рекордами и покупками; многие ко многим для достижений; временные метки, ограничения и уникальность. |
| Формы | Правильные и ошибочные данные для регистрации, входа, игры и профиля. Правка профиля сохраняет заработанный баланс. |
| Страницы | Гостевой доступ, переадресация на вход, 404, создание/чтение/изменение/удаление сохранения, выход. |
| API | Регистрация, выдача и обновление JWT, сохранение и загрузка игры, защита чужих записей, выдача достижения, рейтинг и фильтры. |
| Магазин | Недостаток монет, запрет повторной покупки, списание цены, бонус за клик. |
| Админка | Доступ по роли; XLSX с заданными строками и столбцами; строка с `=` не становится формулой. |
| Безопасность | Строка, похожая на SQL-инъекцию, не выполняется; XSS экранируется; пароль хранится в виде хеша; POST требует CSRF-токен. |
| Запросы к БД | Рейтинг из нескольких записей выполняет один запрос для гостя. |

Покрытие **86%** по выполняемым строкам Python в `game` и `richgame` на SQLite без учёта миграций. В покрытие не входят JavaScript и шаблоны. Браузером отдельно проверены обновление очков, стили и загрузка аватара. Команда начального заполнения проверена при запуске на PostgreSQL, точки входа сервера и все ошибки загрузки файлов не покрыты отдельными тестами.

## Ручной чек-лист

13 ноября 2026 года. Сценарий пройден на локальном сервере с PostgreSQL и `DEBUG=0` в Chrome (с помощью Playwright). Размеры окна имитируют три вида устройств.

| Проверка | Результат |
|---|---|
| Навигация и кнопки | Главная, вход, регистрация, игра, магазин, профиль, рейтинг и выход открываются; кнопки клика, покупки и завершения сработали. |
| Формы | Короткий пароль отклонён; после правильной регистрации открыт вход, после входа — игра; профиль с аватаром сохранён. |
| Полный цикл | Собраны 5 монет, куплено кольцо, сохранение открыто заново, следующий клик дал 2 очка. Игра с 7 очками попала в рейтинг. |
| Права | Гость перенаправлен на вход; обычный игрок не попал в админку; администратор вошёл и выгрузил выбранную сессию в XLSX. |
| Адаптивность | На 1280×900, 768×1024 и 390×844 у главной, игры, магазина, профиля и рейтинга нет горизонтальной прокрутки страницы. CSS применяется, аватар загружается. |
| Ошибки | Несуществующий адрес возвращает собственную страницу с кодом 404; при ошибке формы показано сообщение. |
| Скорость | 15 загрузок пяти основных страниц на трёх размерах окна: 41–173 мс по событию `load`. Это замер на локальном сервере, без внешней сети. |
| Запросы и хранение паролей | Один запрос к БД для публичного списка; проверка хранения хеша пройдена автоматическими тестами. |
| Сопровождение | Запуск описан в README; история разделена на коммиты, работы отмечены тегами. |

Docker не запускался на этом ПК. Проверка сборки, запуска контейнеров, открытия главной и тестов на PostgreSQL предусмотрена в GitHub Actions.
